# Personal Expense Tracker

A simple command-line based Personal Expense Tracker built using Python.

## 📌 Project Overview

The Personal Expense Tracker allows users to record their daily expenses by entering the category, date, and amount.

The program stores the expenses and calculates the total amount spent.

This project was created to practice core Python programming concepts and build a practical real-world application.

## 🚀 Features

* Add personal expenses
* Store expense category
* Store expense date
* Store expense amount
* Display all recorded expenses
* Calculate total expenses
* Interactive command-line interface

## 🛠️ Technologies Used

* Python
* Lists
* Dictionaries
* `while` loop
* `for` loop
* User Input
* Type Conversion

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd Personal-Expense-Tracker
```

3. Run the Python program:

```bash
python expense_tracker.py
```
